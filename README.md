# ALACRAN — Biblia Fractal

## Principio fundacional

ALACRAN toma la **forma de la Biblia Fractal como base estructural**. El repositorio no sustituye la arquitectura bíblica por una arquitectura técnica independiente: la arquitectura técnica debe reflejar la arquitectura del corpus.

## Jerarquía canónica de trabajo

`BIBLIA → BLOQUE → LIBRO → CAPÍTULO → UNIDAD → ELEMENTO → PALABRA → RAÍZ → LETRA_OPERADOR`

### Regla de unidad

La unidad textual no se impone por conveniencia. Se deriva de señales internas del texto: cambios narrativos, discursivos, poéticos, semánticos, operadores y otras evidencias verificables.

### Ciclo fractal

Cada nivel puede reproducir el ciclo:

`00_ORIGEN → 01_MANDATO → 02_DISTINCION → 03_EJECUCION → 04_VALIDACION → 05_CIERRE → 06_TRANSICION → 07_RETORNO`

## Separación epistemológica

- **Texto**: fuente primaria.
- **Dato**: extracción verificable.
- **Análisis**: transformación explícita del dato.
- **Interpretación**: lectura derivada, nunca presentada como dato.
- **Hipótesis**: proposición comprobable o refutable.
- **Auditoría**: control de trazabilidad y consistencia.

## Estado inicial

El mapa maestro de la Biblia Fractal está definido en `00_ORIGEN/BIBLIA_FRACTAL_MAP.json`.

La expansión de capítulos, unidades, elementos, palabras, raíces y letras/operadores se hará desde el corpus y conservará esta jerarquía.
